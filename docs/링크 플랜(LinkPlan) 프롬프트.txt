#요구 사항
  - 할 일 CRUD(생성 / 수정 / 삭제)
  - 상태 관리(시작 전 / 진행 중 / 완료)
  - 드래그 앤 드롭으로 상태 변경
  - 기간 별 할 일의 유기적인 연결 : 일일 / 주간 / 월간 / 연간 목표
  - 구조 연결 : 할 일 → 주간 계획 → 월간 계획 → 연간 목표
  - 새로 만드는 할 일은 주간, 월간, 연간 계획 및 목표와 1개 이상 연결되거나, 아니면 독립적으로 수행할 일로 설정할 수 있어야 함. (예1) 클로드 코드 책 읽기 → (월간) 클로드 코드 기능 습득, (연간) 바이브 코딩 앱 개발과 연계 / (예2) 스마트폰 케이스 구입(다른 목표와 연관 없는 개별적인 할 일)
  - 주간, 월간, 연간 목표 진행률 자동 반영
