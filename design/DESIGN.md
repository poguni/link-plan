# 링크 플랜 DESIGN.md

> 이 문서는 Claude Code 가 링크 플랜의 화면을 구현할 때 따르는 **디자인 기준서**입니다.
> 기능·데이터는 `PRD.md`, 색·간격 값은 `tokens.css`, 눈으로 확인할 기준 화면은 `mockups/*.html` 입니다.
> 값이 서로 다르면 **mockups → DESIGN.md → tokens.css** 순으로 우선합니다(시안이 최종 기준).

시안은 **정적 HTML** 입니다(인라인 스타일, 동작 없음). 그대로 복사하지 말고, 값·배치·구조를 읽어 컴포넌트와 CSS 변수로 다시 구현합니다.

### 0-2. 뷰와 테마의 책임 분리 (가장 중요한 규칙)

- **테마가 바꾸는 것**: 색, 서체, 모서리 반지름, 그림자, 장식(점무늬·마스킹테이프·배너), 상단 셸 종류.
- **뷰가 바꾸는 것**: 본문 배치(3열 칸반 ↔ 노드 그래프), 좌측 목표 패널의 표시 방식.
- **데이터·기능은 6가지 모두 같습니다.** 화면마다 기능이 달라지면 안 됩니다.
- 컴포넌트 CSS 에 `#RRGGBB` 를 직접 쓰지 않습니다. 항상 `var(--…)` 를 씁니다.
- 테마 이름을 `if` 로 분기하는 JS 는 피하고, 분기가 필요하면 CSS 의 `[data-theme]` 선택자로 처리합니다.

## 1. 셸(앱 뼈대) — 테마별 프리셋

| | clean | night | pastel |
|---|---|---|---|
| 상단 | 상단바 없음(사이드바에 로고) | **상단바 64px** | **상단바 64px**(둥근 알약형, 배너 포함) |
| 좌측 | **사이드바 232px** (보드 뷰) / **레일 72px** (링크 뷰) | **좌측 목표 패널 248px** (보드 뷰) / **숨김** (링크 뷰) | **좌측 목표 패널 248px** (보드 뷰) / **숨김** (링크 뷰) |
| 뷰 전환 | 사이드바의 「보드 뷰」「링크 뷰」 항목 | 상단바 가운데 세그먼트(보드 뷰 \| 링크 뷰) | 상단바 가운데 세그먼트 |
| 기간 전환 | 본문 상단 세그먼트(일일·주간·월간·연간) + 이전/다음 | 상단바 우측 세그먼트 + `‹ 9월 4주차 ›` | 상단바 우측 세그먼트 + 이전/다음 |
| 새 할 일 | 본문 상단 오른쪽 기본 버튼 | 상단바 우측 밝은 버튼(`+ 새 할 일`) | 상단바 우측 핑크 버튼 |

셸 규칙
1. 셸은 테마가 결정하고 뷰는 셸을 바꾸지 않습니다. 단, 좌측 목표 패널의 폭/표시는 뷰에 따라 위 표대로 바뀝니다.
2. 링크 뷰는 가로 공간이 필요해서 좌측 패널을 접습니다(clean 은 아이콘 레일, 나머지는 숨김). 숨긴 목표 목록은 링크 뷰 첫 열(연간 목표)이 대신합니다.
3. 클린 사이드바 항목 순서: 로고 → 새 할 일(강조) → 보드 뷰 / 링크 뷰 → 목표 목록(연간·월간·주간 요약) → 하단 사용자 영역.
4. 사용자 영역(모든 테마): 아바타(`i-user`) + 이메일 + 메뉴(로그아웃, 관리자면 「관리자 페이지」). 시안에는 아바타 자리만 있으므로 메뉴는 10절 기준으로 구현합니다.

## 3. 아이콘

Lucide(ISC 라이선스) 를 **인라인 SVG 스프라이트**로 씁니다. 파일: `icons.svg` (27개). 페이지 맨 앞에 한 번 넣고 `<use>` 로 참조합니다.

```html
<svg class="ic" width="18" height="18" viewBox="0 0 24 24" aria-hidden="true"><use href="#i-link"/></svg>
```
```css
.ic { fill: none; stroke: currentColor; stroke-width: 2; stroke-linecap: round; stroke-linejoin: round; flex-shrink: 0; }
```

| id | 용도 |
|---|---|
| `i-link` / `i-unlink` | 링크 뷰, 연결 / 연결 없음(개별) |
| `i-dashboard` | 보드 뷰 |
| `i-flag` | 연간 목표 |
| `i-calendar-days` | 월간 계획 |
| `i-calendar` | 주간 계획, 날짜 |
| `i-circle` / `i-clock` / `i-circle-check` | 상태: 시작 전 / 진행 중 / 완료 |
| `i-check` | 체크 표시 |
| `i-grip` | 끌기 손잡이(장식, 대비 예외) |
| `i-plus` | 새 할 일·추가 |
| `i-search` | 검색 |
| `i-pencil` / `i-trash` / `i-x` | 편집 / 삭제 / 닫기 |
| `i-chev-l` / `i-chev-r` / `i-chevs-r` | 이전·다음 / 접기 |
| `i-layers` | 상태 트레이 |
| `i-inbox` | 빈 상태 |
| `i-user` | 사용자 |
| `i-sparkles` | 안내 문구(끌어다 놓기 힌트) |
| `i-sun` `i-star` `i-sprout` `i-corner` | 파스텔 장식·포인트 |

규칙
- 이모지 사용 금지. 아이콘은 항상 글자와 짝을 이루거나 `aria-label` 을 붙입니다(아이콘만 있는 버튼).
- 시안에 없는 아이콘(로그인·관리자 화면용)은 **같은 Lucide 세트**에서 추가합니다: `log-out`, `shield-check`, `key-round`, `download`, `users`, `user-check`, `user-x`, `mail`, `lock`, `eye`, `eye-off`, `triangle-alert`, `refresh-cw`. 선 굵기 2, 24×24 viewBox 고정.

## 5. 보드 뷰 (3개 테마 공통 배치)

기준 1280×820.

```
┌────────────────────────── 셸(테마별) ───────────────────────────┐
│ [좌측 목표 패널]   │  열1 시작 전  │  열2 진행 중  │  열3 완료  │
│  연간 목표 카드     │  카드…         │  카드…          │  카드…       │
│  월간/주간 요약      │  + 새 할 일     │                   │             │
└───────────────────────────────────────────────────────────────┘
```

- 열 3개 동일 너비(남는 폭을 3등분), 열 사이 16px. 열 머리: 상태 아이콘 + 「시작 전 / 진행 중 / 완료」 + 개수.
- 열 배경은 `--column`(pastel 은 열마다 다른 색). 카드는 `--surface`.
- 좌측 목표 패널: 연간 목표 → 아래에 월간 → 주간 순 요약 카드(단계 칩 + 제목 + 진행 막대). 목표 카드를 클릭하면 본문이 해당 목표에 연결된 할 일만 보이도록 필터됩니다(다시 클릭하면 해제).
- 개별 할 일(연결 없음)은 같은 열에 섞여 있고 「개별」 칩으로 표시합니다. 목록 하단 「연결 없음」 필터 항목이 있습니다.
- 드래그 앤 드롭(SortableJS): 열 사이 이동 = 상태 변경, 열 안 = 정렬. 드래그 중 카드는 살짝 기울고(rotate 2°) `--shadow-drag`, 자리표시자는 점선 박스. 놓은 열은 테두리 강조.
- 완료 열로 이동하면 연결된 주간·월간·연간 진행률이 즉시 다시 계산됩니다(PRD 자동 진행률).
- pastel 보드만의 장식: 열 머리 위 마스킹테이프, 상단 배너(격려 문구), 점무늬 배경. 기능·정보는 다른 테마와 동일해야 합니다.

## 6. 링크 뷰 (3개 테마 공통 배치, 좌표는 시안 기준)

링크 뷰는 **왼쪽에서 오른쪽으로 연간 → 월간 → 주간 → 할 일** 4열 노드 그래프입니다. 노드를 곡선으로 잇고, 아래에 **상태 트레이**(시작 전/진행 중/완료 드롭 영역)를 둡니다.

### 6-1. 열 배치 (x 는 캔버스 왼쪽 기준 px)

| | clean | night / pastel |
|---|---|---|
| 열 x 시작 | 96 / 400 / 704 / 1008 | 40 / 360 / 680 / 1000 |
| 노드 너비 | 224 | 240 |
| 열 피치 | 304 | 320 |
| 좌측 | 72px 레일 | 없음(패널 숨김) |

열 머리(y≈80~90): 아이콘 + 「연간 목표 · 2」 「월간 계획 · 3」 「주간 계획 · 3」 「연결된 할 일 · 7」 (개수 포함).
pastel 은 night 와 같은 x 이고 **세로 위치가 +12px** 입니다(더 둥근 카드의 여백).

### 6-2. 노드 높이·세로 위치 (night·clean 기준, pastel 은 +12)

| 종류 | 높이 | top 값 (위에서부터) |
|---|---|---|
| 할 일 | 56 | 110, 174, 238, 302, 382, 446, 526 |
| 주간 | 84 | 224, 400, 512 |
| 월간 | 84 | 190, 400, 512 |
| 연간 | 104 | 285, 502 |
| 「연결 없음 · 개별 할 일」 머리 | — | y = 606, 노드 y = 632 |
| 상태 트레이 | 164 | y = 632 (개별 열과 겹치지 않도록 좌측 3열 아래) |

레이아웃 알고리즘(구현 시): 부모 노드는 자식 노드들의 **세로 중앙**에 맞춥니다. 형제 사이 간격 8~16px, 그룹(같은 주간에 속한 할 일들) 사이 간격 24px 안팎. 시안의 위 표는 이 규칙을 적용한 결과이므로 샘플 데이터(`sample-data.json`)로 렌더링했을 때 같은 배치가 나오는지 검증 기준으로 씁니다.

### 6-3. 연결선 (세 테마 모두 같은 규칙, 굵기·색만 테마별)

- 선은 **부모 노드 오른쪽 가운데 → 자식 노드 왼쪽 가운데**를 잇습니다. 시안 예시(night): 연간 `M280 337 C 320 337, 320 232, 360 232`.
- 두 점의 y 가 같으면 직선 `M x1 y H x2`, 다르면 3차 베지어 `M x1 y1 C (x1+g) y1, (x2-g) y2, x2 y2` 이고 `g = (x2 - x1) / 2` 입니다(시안: 노드 사이 간격 80px → g = 40).
- **색은 부모 단계 색**입니다(3개 테마 공통): 연간→월간 = 연간 막대색, 월간→주간 = 월간 막대색, 주간→할 일 = 주간 막대색. 테마별 선 표현:

| | 굵기 | 불투명도 | 끝 모양 |
|---|---|---|---|
| clean | 2px | .60~.65 | 기본 |
| night | 2px | .65 | 기본 |
| pastel | 3px | 1 | `stroke-linecap: round` |

- **단계를 건너뛴 연결**(할 일이 월간·연간에 직접 연결)은 다른 색으로 구분합니다.
  - 월간→할 일(직접): 실선, 할 일 왼쪽 점 → 월간 오른쪽 점을 큰 곡선으로 잇는다(시안 night `M1000 138 C 800 138, 800 232, 600 232`, 제어점 x 는 양끝 사이를 2:1·1:2 로 나눈 지점(시안 값 그대로)). 색: clean `#2557D6`(.85), night `#7FB2FF`, pastel `#3F7FBF`.
  - 연간→할 일(직접): **점선** 직각 경로(모서리 반지름 16px)로 노드들 위쪽 여백을 돌아 연간 오른쪽 점으로 들어간다(시안 night `M1000 138 H 336 Q 320 138 320 154 V 321 Q 320 337 304 337 H 280`). 점선 패턴: clean·night `5 6`, 굵기 1.5, 불투명도 .6 / pastel `2 8`, 굵기 2.5, round 캡.
- 끝점 원(지름 8~10px, `fill: --surface`, `stroke: 선 색`)은 노드 위에 HTML/SVG 로 얹습니다.
- 개별 할 일은 선이 없습니다.
- SVG 레이어는 노드 아래, `pointer-events: none` 입니다. 노드는 `position: absolute` 로 좌표를 갖고, 선은 노드의 실제 위치를 읽어 다시 그립니다(리사이즈·스크롤·드래그 후).

### 6-4. 노드 내용

- 연간/월간/주간 노드: 단계 라벨(아이콘+글자) · 제목(700) · 「n/m 완료」 · 오른쪽에 진행 링(44px). 주간 100% 는 굵은 링과 「주간 계획 · 달성」.
- 할 일 노드: 상태 아이콘 + 제목 + 보조 줄(날짜) + 끌기 손잡이. 연결이 2개 이상이면 오른쪽에 `i-link 2` 배지.
- 「옮기는 중」 카드(드래그 원본 자리): 점선 테두리, 투명도 낮춤.

### 6-5. 상태 트레이

- 3칸(시작 전 / 진행 중 / 완료). 각 칸: 상태 아이콘 + 이름 + 큰 숫자(개수) + 점선 드롭존과 안내(「끌어다 놓아 되돌리기」「지금 손대고 있는 일」「여기에 놓으면 완료」).
- 완료 칸이 활성일 때 초록 점선·옅은 배경, 우상단에 「주간 33% → 67%」 같은 **진행률 미리보기 칩**을 보여 줍니다.
- 시안의 유령 카드(드래그 중 모습)는 완료 칸 오른쪽 가장자리를 가리지 않도록 배치돼 있습니다. 구현에서는 커서를 따라 움직입니다.
- 트레이 위 힌트 한 줄: `i-sparkles` + 「노드의 점을 다른 계획으로 끌다 놓으면 새로 이어져요」.

### 6-6. 링크 뷰 상호작용(시안에 없음, 필수 구현)

1. 노드 오른쪽 점을 끌어 다른 열의 노드 왼쪽 점에 놓으면 연결 생성. 규칙 위반(단계 건너뜀 등)은 PRD 5장의 제약 함수(`check_plan_parent`)로 서버에서도 거부하고, UI 는 토스트로 이유를 보여 줍니다.
2. 연결선을 클릭하면 삭제 버튼. 삭제 후 할 일은 개별 상태가 됩니다.
3. 할 일 카드를 트레이의 다른 칸으로 드래그하면 상태 변경 + 진행률 미리보기 → 확정.
4. 노드 호버/포커스 시 그 노드에 이어진 선만 강하게(나머지 40% 투명).
5. 화면보다 노드가 많으면 그래프 영역만 가로·세로 스크롤(트레이는 고정).

## 7. 상태와 상호작용 (시안 밖 규칙 — 구현 시 아래를 따르세요)

| 상태 | clean | night | pastel |

## 8. 접근성

- 본문 글자 대비 4.5:1 이상, 큰 글자(18px+/14px 굵게)·그래픽(링, 아이콘) 3:1 이상. 6개 시안 117개 색 쌍을 계산한 결과 **장식용 끌기 손잡이 2건**(clean `#9AA3B2`/흰색 2.54, pastel `#A59292`/흰색 2.95)을 제외하고 모두 통과합니다. 손잡이는 `aria-hidden` 이고 카드 전체가 드래그 대상이므로 예외로 둡니다.
- 시안 검수 중 고친 항목: pastel 「새 할 일 추가」 `#B04A6D`→`#A23F62`(4.40→5.2), clean 주간 링 트랙 `#F4DDBE`→`#FAE9CF`(2.97→3.29).
- 상태·단계는 색만으로 표현하지 않습니다(아이콘+글자 병행).
- 드래그 앤 드롭은 **키보드 대안**을 제공합니다: 카드에서 Enter → 「상태 변경」 메뉴(시작 전/진행 중/완료). 링크 연결은 편집 모달의 「연결할 계획」 선택 목록으로도 가능해야 합니다.
- 진행 링·막대에 `role="progressbar"` + `aria-valuenow`. 그래프 노드는 `role="group"` 에 `aria-label`(예: 「주간 계획, 책 1~3장 읽기, 33%」).
- 링크 뷰의 연결 정보는 접근 가능한 텍스트로도 제공(노드 상세에 「상위: …」「하위: …」).
- 언어 `lang="ko"`. 포커스 이동 순서는 시각 순서(좌→우, 위→아래)와 같게.

## 12. 알려진 한계

- 시안은 정적입니다. hover·드래그·모달·빈 상태·오류·로딩·반응형·로그인/관리자 화면은 시안이 없고 위 규칙으로 구현합니다.

- 시안은 인라인 스타일로 만들어졌고 폰트는 Google Fonts CDN 을 씁니다. 구현에서는 CSS 클래스와 변수로 정리하세요.
- 나이트의 「보조 색(`#8E9AB3` 등)」과 파스텔의 세부 보조 색은 시안에서 직접 확인하세요(시안이 기준).
